---
title: GET /v1/studio/conversations/{id}/analysis
description: The analysis of one Studio conversation, with its summary, satisfaction, follow-up, questions and your custom fields.
---

import { TypeTable } from 'fumadocs-ui/components/type-table';

After a conversation with one of your Studio agents ends, Studio analyses it: a summary, the customer's satisfaction, whether it was resolved, its priority, whether a person should step in, the follow-up you owe, the questions the customer asked, and the custom fields and success criteria you set on the agent. This endpoint returns that analysis.

Where you corrected a label in Studio, you get your correction, as the inbox and the CSV export show it. That covers the sentiment at the end, the contact type, the resolution, the priority, whether a person should step in, and the lead temperature. Conversations from the agent test panel are not returned.

```bash
curl https://api.addisassistant.com/v1/studio/conversations/c1000000-0000-4000-8000-000000000010/analysis \
  -H "x-api-key: $ADDIS_API_KEY"
```

<Callout type="info" title="The same shape as the webhook">
The `call.analyzed` webhook sends this shape too, without `started_at`, `analysed_at` and each question's `topic_id`. The webhook always carries the labels as Studio first worked them out; this endpoint also shows your corrections. A conversation is analysed again when you ask for it in Studio, and this endpoint always returns the latest analysis.
</Callout>

## Errors

| Status | Code | Meaning |
| :--- | :--- | :--- |
| 401 | `unauthorized`, `invalid_api_key` | The `x-api-key` header is missing or not a valid key. |
| 404 | `analysis_not_found` | No analysis of this conversation in your account: the ID is wrong, the conversation is not yours, it has not been analysed yet, or it came from the agent test panel. |
| 429 | `risk_rate_limited` | Your account is temporarily limited. See [Rate Limits](/docs/platform/limits). |

Errors use the [error object](/docs/platform/errors).
