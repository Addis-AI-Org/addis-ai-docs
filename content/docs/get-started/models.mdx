# Models and capabilities

| Capability | Status | Languages | Select with |
| --- | --- | --- | --- |
| Chat and multimodal | GA | Amharic, Afan Oromo | `chat.completions.create` |
| Addis Voice 2 | GA | Query the voice catalog | `voice.generate` |
| Speech-to-text | GA | `am`, `om`, `en`, `ha`, `sw` | `speech.transcribe` |
| Translation | GA | `am`, `om`, `en` | `translate.create` |
| Realtime Audio | Beta | Amharic, Afan Oromo | WebSocket API |

The platform selects the production chat model. Although compatibility payloads may contain `model`, applications should select the capability, language, and voice rather than depend on an internal model identifier.

For Voice 2, call `voices.list` at configuration time and save a returned voice ID. This keeps applications aligned with the production catalog.
