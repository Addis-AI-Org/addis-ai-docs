## Why Addis AI?

African languages are not an edge case here. The platform is designed around the morphology, scripts, accents, and cultural context of the languages it serves.

1. **Language-native models** handle Amharic and Afan Oromo as primary data instead of adding a translation layer to every request.
2. **Local context** improves answers about regional history, geography, language use, and everyday communication.
3. **Text and voice together** let one application understand input, reason over it, and answer in natural speech.

## The core engines

- **Addis text and multimodal** — chat, instruction following, analysis, translation, and file input.
- **Addis Voice 2 and speech-to-text** — voice discovery, preview, speech generation, and transcription.
- **Realtime Audio (Beta)** — low-latency conversations with interruption and live audio events.

Use [Models and capabilities](/docs/get-started/models) when you need the detailed language and feature matrix.

## The shortest path to your first request

The [Quick Start](/docs/get-started/quickstart) shows every screen: test a prompt in Playground, create and copy an API key, install the official Node.js or Python SDK, and run a request. No prior knowledge of the platform is assumed.

Use the official `addisai` SDK whenever one is available. cURL is included beside every first-party example for developers using another runtime.
