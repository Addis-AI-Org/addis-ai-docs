## Install

<Tabs items={['Node.js', 'Python']}>
  <Tab value="Node.js">
    ```bash
    npm install addisai
    ```

    [View on npm](https://www.npmjs.com/package/addisai)
  </Tab>
  <Tab value="Python">
    ```bash
    pip install addisai
    ```

    [View on PyPI](https://pypi.org/project/addisai/)
  </Tab>
</Tabs>

## Create a client

Set your key in the server environment:

```bash
export ADDIS_API_KEY="your_api_key"
```

<Tabs items={['Node.js', 'Python']}>
  <Tab value="Node.js">
    ```ts
    import AddisAI from "addisai";

    const addis = new AddisAI();
    ```
  </Tab>
  <Tab value="Python">
    ```python
    from addisai import AddisAI

    addis = AddisAI()
    ```
  </Tab>
</Tabs>

The SDKs read `ADDIS_API_KEY` by default. Keep this key on a trusted server—never in browser JavaScript, a mobile binary, or a public environment variable.
