## Authentication

Authentication is handled via a secret `x-api-key` header.

## Base URLs

REST API requests use the following production base URL:

```bash
https://api.addisassistant.com
```

Realtime voice uses a separate WebSocket endpoint:

```bash
wss://relay.addisassistant.com/ws
```

For Addis Voices 2 text-to-speech streaming, use `wss://api.addisassistant.com/api/v1/realtime/voice` with a scoped session ticket. Follow the [Streaming text-to-speech guide](/docs/capabilities/text-to-speech/streaming) for session creation and SDK release availability.

## Endpoints

| Capability | Endpoint | Method |
| --- | --- | --- |
| Chat and Text Generation | `/api/v1/chat_generate` | `POST` |
| Text-to-Speech (Addis Voices 2) | `/api/v1/voice/generations` | `POST` |
| Speech-to-Text | `/api/v2/stt` | `POST` |
| Translation | `/api/v1/translate` | `POST` |
| Multimodal | `/api/v1/chat_generate` | `POST multipart/form-data` |
| Realtime Voice | `wss://relay.addisassistant.com/ws` | `WebSocket` |
