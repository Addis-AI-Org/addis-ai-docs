# Quickstart

Create an API key in the [developer portal](https://addisassistant.com/apikeys), then store it on your server:

```bash
export ADDIS_API_KEY="your_api_key"
```

Never expose an API key in browser or mobile application code.

## 1. Install the SDK

## 2. Generate a chat response

<Tabs items={['Node.js', 'Python']} groupId="sdk-language">
  <Tab>
```ts
import AddisAI from "addisai";

const addis = new AddisAI();
const response = await addis.chat.completions.create({
  messages: [{ role: "user", content: "በአማርኛ ሰላም በል" }],
});

console.log(response.choices[0].message.content);
```
  </Tab>
  <Tab>
```python
from addisai import AddisAI

addis = AddisAI()
response = addis.chat.completions.create(
    messages=[{"role": "user", "content": "በአማርኛ ሰላም በል"}],
)

print(response["choices"][0]["message"]["content"])
```
  </Tab>
</Tabs>

## 3. Generate speech with Addis Voice 2

`am-hamen` is the canonical example voice. Discover production voices with `addis.voices.list()` before persisting a voice ID.

<Tabs items={['Node.js', 'Python']} groupId="sdk-language">
  <Tab>
```ts
const clip = await addis.voice.generate({
  text: "ሰላም፣ እንኳን ወደ አዲስ ኤአይ በደህና መጡ።",
  voiceId: "am-hamen",
  language: "am",
  outputFormat: "mp3_44100",
});

await clip.toFile("welcome.mp3");
```
  </Tab>
  <Tab>
```python
clip = addis.voice.generate(
    text="ሰላም፣ እንኳን ወደ አዲስ ኤአይ በደህና መጡ።",
    voice_id="am-hamen",
    language="am",
    output_format="mp3_44100",
)

clip.to_file("welcome.mp3")
```
  </Tab>
</Tabs>
