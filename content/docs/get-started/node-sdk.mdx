---
title: Node.js SDK
description: Install and configure the official Addis AI JavaScript and TypeScript SDK.
---


The official Node.js SDK supports Node.js 18+, Bun, Deno, Cloudflare Workers, and Vercel Edge.

Latest live-verified package: `addisai@0.1.2` (2026-07-17).

```bash
npm install addisai
```

```ts
import AddisAI from "addisai";

const addis = new AddisAI({
  apiKey: process.env.ADDIS_API_KEY,
  timeout: 30_000,
  maxRetries: 2,
});
```

The client exposes `chat`, `voice`, `voices`, `speech`, and `translate` resources. It refuses browser execution by default because a browser cannot protect a secret API key. Do not enable browser access for production applications.

Voice 2 is billed by generated minutes. The `0.1.2` Voice estimate and usage TypeScript declarations still contain retired character-pricing fields; see the [Voice 2 guide](/docs/guides/voice) before consuming pricing fields.

See the [Node.js SDK reference](/docs/reference/node) and [npm package](https://www.npmjs.com/package/addisai).
