# Announcements

Product and developer-platform updates from Addis AI.

## July 17, 2026

### Addis Voice 2 is available

<StatusBadge>New</StatusBadge>

Addis Voice 2 introduces a production voice catalog, previews, cost estimates, durable generated clips, idempotent requests, and minute-based billing at **5 ETB per generated minute**. Use `am-hamen` for the minimal Amharic example, then query the catalog before saving a voice for production.

[Build with Addis Voice 2 →](/docs/guides/voice)

### Official Node.js and Python SDKs

<StatusBadge>New</StatusBadge>

The official `addisai` packages are now the recommended way to integrate Addis AI. The documentation leads with Node.js and Python examples, while raw REST remains available for unsupported runtimes and interoperability.

- [Install the Node.js SDK](/docs/get-started/node-sdk)
- [Install the Python SDK](/docs/get-started/python-sdk)
- [View the package on npm](https://www.npmjs.com/package/addisai)
- [View the package on PyPI](https://pypi.org/project/addisai/)

### New chat controls

<StatusBadge>New</StatusBadge>

Chat requests now document system instructions, personas, and structured function calls. System instructions control behavior, personas define identity, and messages preserve conversation state. Function calling remains Beta while coordinated SDK fixes are completed.

- [System instructions](/docs/core-concepts/system-instructions)
- [Personas](/docs/core-concepts/personas)
- [Function calling — Beta](/docs/core-concepts/function-calling)

### SDK-first documentation

The documentation has been reorganized around outcomes, official SDK examples, production guidance, and secondary raw REST requests. Existing documentation URLs permanently redirect to their current pages.
