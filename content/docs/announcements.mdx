Product and developer-platform updates from Addis AI.

## July 23, 2026

### Addis Voice 2 is available

<NewBadge />

Addis Voice 2 introduces a production voice catalog, previews, cost estimates, durable generated clips, idempotent requests, and minute-based billing at **5 ETB per generated minute**. Use `am-hamen` for the minimal Amharic example, then query the catalog before saving a voice for production.

[Build with Addis Voice 2 →](/docs/capabilities/text-to-speech)

### Official Node.js and Python SDKs

<NewBadge />

The official `addisai` packages are now the recommended way to integrate Addis AI. The documentation leads with Node.js and Python examples, while raw REST remains available for unsupported runtimes and interoperability.

- [Install the official SDKs](/docs/get-started/sdks)
- [View the package on npm](https://www.npmjs.com/package/addisai)
- [View the package on PyPI](https://pypi.org/project/addisai/)

### New chat controls

<NewBadge />

Chat requests now document system instructions, personas, and structured function calls. System instructions control behavior, personas define identity, and messages preserve conversation state.

- [System instructions and personas](/docs/capabilities/text-generation#system-instructions-and-personas)
- [Function calling](/docs/capabilities/text-generation#function-calling)

### SDK-first documentation

The documentation has been updated in place around official SDK examples, production guidance, and complete capability best practices.
