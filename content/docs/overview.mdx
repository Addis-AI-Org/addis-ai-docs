# Build with Addis AI

Addis AI provides chat, Addis Voice 2, speech-to-text, translation, multimodal input, and realtime audio APIs. The official `addisai` SDKs are the recommended integration; raw REST is available for interoperability.

## Start here

- [Quickstart](/docs/get-started/quickstart) — make your first chat and Voice 2 requests.
- [Node.js SDK](/docs/get-started/node-sdk) and [Python SDK](/docs/get-started/python-sdk) — install and configure the official packages.
- [Core concepts](/docs/core-concepts/messages) — understand messages, system instructions, personas, and tools.
- [Pricing](/docs/platform/pricing) — see native ETB billing units.
- [API reference](/docs/reference/rest) — inspect the versioned REST contract.

Use the [developer portal](https://addisassistant.com), [API keys](https://addisassistant.com/apikeys), [Playground](https://addisassistant.com/playground), and [Voice Lab](https://addisassistant.com/voice) for account and interactive workflows. Package source is available on [GitHub for Node.js](https://github.com/Addis-AI-Org/addisai-js) and [GitHub for Python](https://github.com/Addis-AI-Org/addisai-py).

## Languages and capabilities

Amharic (`am`) and Afan Oromo (`om`) are the primary platform languages. Some capabilities support additional languages; see [models and capability selection](/docs/get-started/models) for the precise matrix.
