Addis AI bills natively in Ethiopian birr (ETB). Any USD or EUR amount shown in account tools is an indicative conversion and can change with the exchange rate.

## Current Pricing

| Capability | Billing unit | Price |
| :--- | :--- | :--- |
| **Addis Voice 2** | Generated audio | **5 ETB / minute** |
| **Text Generation & Translation — Input** | Input tokens | **0.3 ETB / 1,000 tokens** |
| **Text Generation & Translation — Output** | Output tokens | **0.8 ETB / 1,000 tokens** |
| **Speech to Text** | Transcribed output | **3.5 ETB / 1,000 characters** |
| **Realtime Audio — Input** | Input tokens | **1 ETB / 1,000 tokens** |
| **Realtime Audio — Output** | Output tokens | **4 ETB / 1,000 tokens** |

<Callout type="info" title="Voice 2 estimates">
Use `voice.estimate` before generation when a user must approve spend. The estimate reports the expected duration, billable duration, cost, balance, currency, and whether generation can proceed.
</Callout>
