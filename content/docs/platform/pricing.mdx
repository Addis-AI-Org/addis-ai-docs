Addis AI bills natively in Ethiopian birr (ETB). Any USD or EUR amount shown in account tools is an indicative conversion and can change with the exchange rate.

## Current Pricing

<Callout type="info" title="Launch promo: 50% off Addis Voices 2 and Addis Scribe">
Until the end of **November 12, 2026** (East Africa Time), Addis Voices 2 is **2.5 ETB / minute** and Speech to Text (Addis Scribe) is **1.75 ETB / 1,000 characters**, for every account. The discount is applied automatically and shows in the usage returned with each request. List prices in the table below apply again from November 13.
</Callout>

| :--- | :--- | :--- |
| **Addis Voices 2** | Generated audio | **5 ETB / minute** |
| **Text Generation & Translation (Input)** | Input tokens | **0.3 ETB / 1,000 tokens** |
| **Text Generation & Translation (Output)** | Output tokens | **0.8 ETB / 1,000 tokens** |
| **Speech to Text** | Transcribed output | **3.5 ETB / 1,000 characters** |
| **Realtime Audio (Input)** | Input tokens | **1 ETB / 1,000 tokens** |
| **Realtime Audio (Output)** | Output tokens | **4 ETB / 1,000 tokens** |

Speech to Text (Addis Scribe) charges the same per-character rate for Amharic, Afaan Oromo and Tigrinya, on Standard and Turbo alike.

<Callout type="info" title="Addis Voices 2 estimates">
Use `voice.estimate` before generation when a user must approve spend. The estimate reports the expected duration, billable duration, cost, balance, currency, and whether generation can proceed.
</Callout>

## Voice streaming billing

[Streaming text-to-speech](/docs/capabilities/text-to-speech/streaming) uses the Addis Voices 2 generated-audio rate above. Its HTTP and WebSocket speech output is billed by measured duration. The Realtime Audio input/output token rates apply to the separate [Realtime API](/docs/capabilities/realtime).

A text-based estimate can differ from the final charge. Read the confirmed usage after streaming completes, and reuse the original request ID and inputs for a recovery request to avoid another charge.
