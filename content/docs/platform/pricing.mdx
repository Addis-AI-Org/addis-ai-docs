Prices are billed natively in Ethiopian birr (ETB). USD and EUR displays in account tools are indicative conversions and may change with the exchange rate.

Realtime Audio is Beta; a typical session is approximately 13 ETB per minute, but actual billing depends on token usage. Translation follows language-model token pricing. Eligible new accounts currently receive 500 ETB in signup credit.

The table is built from pricing data checked into this documentation project and verified during releases. The developer portal remains authoritative for current account balances and interactive estimates.
