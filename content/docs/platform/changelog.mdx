# Changelog

## 2026-07-17 — SDK-first documentation release

- Reorganized documentation around official Node.js and Python SDKs.
- Added a release [Announcements](/docs/announcements) page and “New” navigation labels for the new SDK, Voice 2, and chat-control documentation.
- Added Addis Voice 2 guidance using canonical voice `am-hamen`.
- Documented minute-based Voice 2 billing at 5 ETB per generated minute.
- Added system instructions, personas, streaming, multimodal concepts, and the current Function Calling Beta limitations.
- Added a validated OpenAPI 3.1 contract and private build-time pricing data.
- Consolidated legacy voice content into the deprecation and migration guide.
- Marked Realtime Audio and function calling as Beta; function calling remains non-streaming and blocked on coordinated SDK fixes.
- Documented the published SDK billing-field limitations that remain pending coordinated Node.js and Python releases.
- Added permanent redirects for renamed documentation routes, canonical page metadata, sitemap generation, and `llms-full.txt` coverage.
- Removed the legacy browser API-key Realtime demo; browser and mobile integrations now require a developer-owned backend or short-lived user session.
