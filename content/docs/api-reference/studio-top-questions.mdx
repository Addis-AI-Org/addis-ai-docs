title: GET /v1/studio/agents/{agent_id}/top-questions

import { TypeTable } from 'fumadocs-ui/components/type-table';

Studio files every question a customer asks under a topic. This endpoint returns an agent's topics for a period, the most asked first, with how many conversations raised each one, how often the agent could not answer, and a few of the ways customers put it. These are the numbers on the Top questions card in Studio Analytics.

```bash
curl "https://api.addisassistant.com/v1/studio/agents/a1000000-0000-4000-8000-000000000010/top-questions?since=2026-10-01" \
  -H "x-api-key: $ADDIS_API_KEY"
```

Conversations from the agent test panel are not counted.

## Errors

| Status | Code | Meaning |
| :--- | :--- | :--- |
| 400 | `invalid_request` | A query parameter is not valid; `error.param` names it. |
| 400 | `invalid_range` | since is not before until, or the period is longer than 366 days. |
| 401 | `unauthorized`, `invalid_api_key` | The `x-api-key` header is missing or not a valid key. |
| 404 | `agent_not_found` | No such agent in your account. |
| 429 | `risk_rate_limited` | Your account is temporarily limited. See [Rate Limits](/docs/platform/limits). |

Errors use the [error object](/docs/platform/errors).
