# Addis Voice 2

Addis Voice 2 is billed by generated audio duration at **5 ETB per minute**. Estimate before generating when the user must approve cost.

## Discover and preview voices

<Tabs items={['Node.js', 'Python']} groupId="sdk-language">
  <Tab>
```ts
const catalog = await addis.voices.list({ language: "am" });
const preview = await addis.voices.preview("am-hamen");
console.log(preview.audioUrl);
```
  </Tab>
  <Tab>
```python
catalog = addis.voices.list(language="am")
preview = addis.voices.preview("am-hamen")
print(preview["audio_url"])
```
  </Tab>
</Tabs>

Use the catalog as the source of truth. `am-hamen` is the canonical minimal example, not a substitute for catalog discovery.

## Estimate and generate

<Tabs items={['Node.js', 'Python']} groupId="sdk-language">
  <Tab>
```ts
const input = {
  text: "ሰላም፣ ይህ የአዲስ ድምፅ ሁለት ሙከራ ነው።",
  voiceId: "am-hamen",
  language: "am" as const,
  outputFormat: "mp3_44100" as const,
};

const estimate = await addis.voice.estimate(input);
if (!estimate.canGenerate) throw new Error("Insufficient balance");

const clip = await addis.voice.generate({
  ...input,
  clientRequestId: crypto.randomUUID(),
});
await clip.toFile("speech.mp3");
```
  </Tab>
  <Tab>
```python
input = {
    "text": "ሰላም፣ ይህ የአዲስ ድምፅ ሁለት ሙከራ ነው።",
    "voice_id": "am-hamen",
    "language": "am",
    "output_format": "mp3_44100",
}

estimate = addis.voice.estimate(**input)
if not estimate["can_generate"]:
    raise RuntimeError("Insufficient balance")

clip = addis.voice.generate(**input, client_request_id="order-123")
clip.to_file("speech.mp3")
```
  </Tab>
</Tabs>

Supported output formats are `mp3_44100`, `wav_44100`, and `pcm_16000`. A stable client request ID prevents duplicate generation after uncertain retries.

## Voice settings

`speed` is currently applied. `stability`, `similarity`, and `style` are accepted for compatibility but ignored by the current provider; the response reports them in `meta.ignoredVoiceSettings` or `meta["ignored_voice_settings"]`. Do not build product behavior that assumes ignored settings affect the generated clip.

## Usage and clip history

Use `addis.voice.usage()` for current minute-priced usage. Use `addis.voice.clips.list()`, `.get()`, `.download()`, and `.delete()` to manage generated clips. Historical records may retain character-based pricing fields; current Voice 2 clips are minute-priced.

<Callout type="warn" title="Published SDK billing surfaces">
Node `0.1.2` runs against the minute-priced backend, but some exported Voice estimate and usage TypeScript declarations still describe the retired character-based fields. Python `0.1.1` returns the minute-based estimate and usage summary, but its generated-clip mapper drops `price_per_minute` from `clip.usage`. Treat the estimate endpoint and the [pricing page](/docs/platform/pricing) as authoritative until the coordinated SDK releases are published.
</Callout>

Voice 2 does not currently support streaming. Do not wait for partial audio from `voice.generate`.

<RestDisclosure>
<Endpoint method="POST" path="/api/v1/voice/generations" />

```bash
VOICE_REQUEST_ID="$(uuidgen)"

VOICE_RESPONSE="$(curl --fail-with-body \
  https://api.addisassistant.com/api/v1/voice/generations \
  -H "x-api-key: $ADDIS_API_KEY" \
  -H "content-type: application/json" \
  -d "{\
    \"text\": \"ሰላም\",\
    \"language\": \"am\",\
    \"voice_id\": \"am-hamen\",\
    \"output_format\": \"mp3_44100\",\
    \"client_request_id\": \"$VOICE_REQUEST_ID\"\
  }")"

printf '%s' "$VOICE_RESPONSE" | jq .
VOICE_AUDIO_URL="$(printf '%s' "$VOICE_RESPONSE" | jq -r '.data.audio_url')"
curl --fail --location "$VOICE_AUDIO_URL" --output speech.mp3
```
</RestDisclosure>

Errors include invalid voices, unsupported formats, insufficient balance, rate limiting, and transient generation failures. Validate catalog membership, estimate when needed, retry transient failures with the same idempotency value, and log the clip/request ID.
