Attach files through SDK upload helpers and describe the intended analysis in the user message.

<Tabs items={['Node.js', 'Python', 'cURL']} groupId="integration-language">
  <Tab>
```ts
import { fileFromPath } from "addisai";

const response = await addis.chat.completions.create({
  messages: [{ role: "user", content: "Extract the table and summarize it in Amharic." }],
  attachments: [{ file: await fileFromPath("report.pdf") }],
});
```
  </Tab>
  <Tab>
```python
with open("report.pdf", "rb") as report:
    response = addis.chat.completions.create(
        messages=[{"role": "user", "content": "Extract the table and summarize it in Amharic."}],
        attachments=[report],
    )
```
  </Tab>
  <Tab>
```bash
curl https://api.addisassistant.com/api/v1/chat_generate \
  -H "x-api-key: $ADDIS_API_KEY" \
  -F 'attachment_0=@report.pdf;type=application/pdf' \
  -F 'request_data={"prompt":"Extract the table and summarize it in Amharic.","target_language":"am","attachment_field_names":["attachment_0"]}'
```
  </Tab>
</Tabs>

Reject unexpected formats, cap upload sizes, isolate parsing, and avoid assuming extracted text is trustworthy. The SDK uses the native multipart chat extension for attachments.
