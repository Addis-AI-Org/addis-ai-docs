<StatusBadge>Generally available</StatusBadge>


Translation supports `am`, `om`, and `en` and uses language-model token pricing.

<Tabs items={['Node.js', 'Python', 'cURL']} groupId="integration-language">
  <Tab>
```ts
const result = await addis.translate.create({
  text: "Baga nagaan dhuftan.",
  from: "om",
  to: "en",
});
console.log(result.text);
```
  </Tab>
  <Tab>
```python
result = addis.translate.create(
    text="Baga nagaan dhuftan.",
    source="om",
    target="en",
)
print(result["text"])
```
  </Tab>
  <Tab>
```bash
curl https://api.addisassistant.com/api/v1/translate \
  -H "x-api-key: $ADDIS_API_KEY" \
  -H "content-type: application/json" \
  -d '{"text":"Baga nagaan dhuftan.","source_language":"om","target_language":"en"}'
```
  </Tab>
</Tabs>

Preserve source text for auditability, specify both languages when known, and review high-impact legal, medical, or financial translations with a qualified human.
