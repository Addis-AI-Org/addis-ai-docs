# Text generation and chat

## Generate a response

<Tabs items={['Node.js', 'Python']} groupId="sdk-language">
  <Tab>
```ts
const response = await addis.chat.completions.create({
  persona: "You are a helpful Ethiopian language tutor.",
  system: "Answer in Amharic and include one short example.",
  messages: [{ role: "user", content: "Explain the word እንኳን." }],
});

console.log(response.choices[0].message.content);
console.log(response.usage);
```
  </Tab>
  <Tab>
```python
response = addis.chat.completions.create(
    persona="You are a helpful Ethiopian language tutor.",
    system="Answer in Amharic and include one short example.",
    messages=[{"role": "user", "content": "Explain the word እንኳን."}],
)

print(response["choices"][0]["message"]["content"])
print(response.get("usage"))
```
  </Tab>
</Tabs>

Persist the returned assistant message for multi-turn chat. Use streaming for long text and upload helpers for images, documents, or audio. Retry only transient failures and preserve request identifiers in logs.
