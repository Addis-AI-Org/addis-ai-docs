## Developer Experience

We prioritize simplicity. Since we are API-first, you can use any language that supports HTTP.

### The "Hello World"

Copy this code to generate your first Amharic response. The official Node.js and Python SDKs are the recommended integration; cURL remains available for the raw request.

<Tabs items={['Node.js', 'Python', 'cURL']}>
  <Tab value="Node.js">
    ```ts
    import AddisAI from "addisai";

    const addis = new AddisAI();
    const response = await addis.chat.completions.create({
      messages: [{
        role: "user",
        content: "ሰላም፣ ስለ አድዋ ጦርነት በአጭሩ ንገረኝ።",
      }],
    });

    console.log(response.choices[0].message.content);
    ```
  </Tab>
  <Tab value="Python">
    ```python
    from addisai import AddisAI

    addis = AddisAI()
    response = addis.chat.completions.create(
        messages=[{
            "role": "user",
            "content": "ሰላም፣ ስለ አድዋ ጦርነት በአጭሩ ንገረኝ።",
        }],
    )

    print(response["choices"][0]["message"]["content"])
    ```
  </Tab>
  <Tab value="cURL">
    ```bash
    curl https://api.addisassistant.com/api/v1/chat_generate \\
      -H "X-API-Key: $ADDIS_API_KEY" \\
      -H "Content-Type: application/json" \\
      -d '{
        "prompt": "ሰላም፣ ስለ አድዋ ጦርነት በአጭሩ ንገረኝ።",
        "target_language": "am"
      }'
    ```
  </Tab>
</Tabs>

### Getting your Keys
To run the code above, you need an API Key.
1. Log in to the [Platform Dashboard](https://addisassistant.com).
2. Go to **Settings > API Keys**.
3. Click **Create New Key**.
