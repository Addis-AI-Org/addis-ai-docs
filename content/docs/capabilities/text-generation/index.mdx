The Text Generation API is powered by **`Addis-፩-አሌፍ`**, our flagship large language model.

Use it when your application needs chat, summarization, extraction, classification, RAG, structured output, function calling, or multi-turn conversation in African-language workflows.

Use Text Generation for chat, summarization, extraction, classification, RAG, structured output, and multi-turn conversations. Use the dedicated Translation API for direct language-to-language translation.

## Basic request
Send a prompt and a target language to get an immediate response.

<Tabs items={['Node.js', 'Python', 'cURL']}>
  <Tab value="Node.js">
    ```ts
    import AddisAI from "addisai";

    const addis = new AddisAI();
    const response = await addis.chat.completions.create({
      messages: [{
        role: "user",
        content: "የአድዋ ጦርነት ታሪክ በአጭሩ",
      }],
      temperature: 0.7,
      max_tokens: 500,
    });

    console.log(response.choices[0].message.content);
    ```
  </Tab>
  <Tab value="Python">
    ```python
    from addisai import AddisAI

    addis = AddisAI()
    response = addis.chat.completions.create(
        messages=[{
            "role": "user",
            "content": "የአድዋ ጦርነት ታሪክ በአጭሩ",
        }],
        temperature=0.7,
        max_tokens=500,
    )

    print(response["choices"][0]["message"]["content"])
    ```
  </Tab>
  <Tab value="cURL">
    ```bash
    curl https://api.addisassistant.com/api/v1/chat_generate \
      -H "Content-Type: application/json" \
      -H "x-api-key: $ADDIS_API_KEY" \
      -d '{
        "prompt": "የአድዋ ጦርነት ታሪክ በአጭሩ",
        "target_language": "am",
        "generation_config": {
          "temperature": 0.7,
          "maxOutputTokens": 500
        }
      }'
    ```
  </Tab>
</Tabs>
