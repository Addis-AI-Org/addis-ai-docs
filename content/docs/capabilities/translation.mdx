Translation supports Amharic (`am`), Afan Oromo (`om`), and English (`en`). Source and target languages must differ. Usage follows language-model token pricing.

<Endpoint method="POST" path="/api/v1/translate" />

## Translate text

<Tabs items={['Node.js', 'Python', 'cURL']} groupId="integration-language">

```ts
const result = await addis.translate.create({
  text: "Baga nagaan dhuftan.",
  from: "om",
  to: "en",

console.log(result.text, result.quality);
```

result = addis.translate.create(

## Available parameters

| Value | Node.js | Python | REST | Required |
| --- | --- | --- | --- | --- |
| Text to translate | `text` | `text` | `text` | Yes; must not be empty |
| Source language | `from` | `source` | `source_language` | Yes; `am`, `om`, or `en` |
| Target language | `to` | `target` | `target_language` | Yes; `am`, `om`, or `en` |

Source and target must be different. The supported directions are:

| From | To |
| --- | --- |
| Amharic (`am`) | Afan Oromo (`om`) or English (`en`) |
| Afan Oromo (`om`) | Amharic (`am`) or English (`en`) |
| English (`en`) | Amharic (`am`) or Afan Oromo (`om`) |

## Response handling

The normalized SDK response contains translated text, source language, target language, optional quality, and usage metadata. Preserve the source text when reviewers need to compare or audit a translation.

Quality is a model signal, not a substitute for review. Do not silently publish high-impact content only because the response says `high`.

## Context and terminology

Translate complete sentences or paragraphs when possible. Isolated words often lack the grammatical and cultural context needed for the correct result.

For product names, legal terms, or organization-specific vocabulary, include the intended meaning in the source text or process the output with an approved terminology list.

## Errors and billing

Correct unsupported or identical language pairs and empty input before retrying. Translation consumes language-model tokens; see [Pricing](/docs/platform/pricing) and retain usage metadata when allocating cost by customer or workflow.

## Best Practices

- Specify both source and target languages when they are known.
- Preserve spelling, punctuation, and Fidel consistency in the source.
- Send complete sentences for grammatical context.
- Keep names and product terms unchanged when required, and state that rule explicitly.
- Translate related content in coherent sections instead of unrelated fragments.
- Preserve the source for review and auditability.
- Use qualified human review for legal, medical, financial, safety, or public-policy content.
