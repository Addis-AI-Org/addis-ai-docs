---
title: Messages and conversation state
description: Represent instructions, user input, assistant output, and tool results.
---


The chat API is stateless: each request includes the conversation context required for the next response. Append the assistant response to your local history before sending the next user turn.

```ts
import type { ChatCompletionMessage } from "addisai";

const messages: ChatCompletionMessage[] = [
  { role: "user", content: "Maqaan kee eenyu?" },
];

const first = await addis.chat.completions.create({ messages });
messages.push(first.choices[0].message);
messages.push({ role: "user", content: "Deebii gabaabaa kenni." });
```

Use `user` for end-user input, `assistant` for model responses, and `tool` for trusted results from application functions. The SDK folds OpenAI-style `system` and `developer` messages into the top-level `system` instruction.

Treat history as application data: cap its size, remove secrets, and summarize older turns when appropriate.
