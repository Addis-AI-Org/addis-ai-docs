# Personas

`persona` defines who the assistant is; `system` defines how it must behave. Keeping them separate makes assistants easier to reuse and audit.

<Tabs items={['Node.js', 'Python']} groupId="sdk-language">
  <Tab>
```ts
await addis.chat.completions.create({
  persona: "You are Hana, a patient Addis Ababa travel guide.",
  system: "Reply in the user's language. Do not make bookings.",
  messages: [{ role: "user", content: "ነገ የት ልጎብኝ?" }],
});
```
  </Tab>
  <Tab>
```python
addis.chat.completions.create(
    persona="You are Hana, a patient Addis Ababa travel guide.",
    system="Reply in the user's language. Do not make bookings.",
    messages=[{"role": "user", "content": "ነገ የት ልጎብኝ?"}],
)
```
  </Tab>
</Tabs>

Do not put credentials, private customer data, or authorization decisions in a persona.
