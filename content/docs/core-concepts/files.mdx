# Files, images, and audio input

Use SDK file helpers so filenames, media types, and multipart boundaries are encoded correctly. Validate type and size before upload and avoid retaining sensitive content longer than necessary.

<Tabs items={['Node.js', 'Python']} groupId="sdk-language">
  <Tab>
```ts
import AddisAI, { fileFromPath } from "addisai";

const image = await fileFromPath("receipt.jpg");
const response = await addis.chat.completions.create({
  messages: [{ role: "user", content: "Summarize this receipt in Amharic." }],
  attachments: [{ file: image }],
});
```
  </Tab>
  <Tab>
```python
with open("receipt.jpg", "rb") as image:
    response = addis.chat.completions.create(
        messages=[{"role": "user", "content": "Summarize this receipt in Amharic."}],
        attachments=[image],
    )
```
  </Tab>
</Tabs>

For audio-only transcription, use the dedicated [speech-to-text guide](/docs/guides/speech-to-text).
